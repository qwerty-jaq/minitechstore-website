# Mini Tech Store – Website

Front-end pages for an online tech store, built with HTML and CSS for my ITECA module at Eduvos.

## Pages

- `login.html` – login page
- `register.html` – create an account
- `products.html` – product listing

## Built with

- HTML5
- CSS3 (`css/style.css`)

## How to view

Download the repo and open `login.html` in any web browser.
